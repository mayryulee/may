# 새 클라이언트 — 예식장(주소) 변경 체크리스트

`clients/<클라이언트 폴더>/config.ts` 에서 아래 항목을 **모두** 바꿔야 합니다.
샘플(sample01 등)을 복사해 만들면 예전 예식장 값이 남아 있으므로, 하나라도 빠뜨리면
지도·길찾기 버튼이 엉뚱한 곳(예: 노블발렌티 대치점)으로 이동합니다.

---

## 1. 준비물 (클라이언트에게 받을 것)

- 예식장 이름 (층·홀 포함 여부 결정, 예: `더베일리하우스 삼성점 2F`)
- 도로명 주소 / 지번 주소
- 예식장 전화번호
- **네이버 지도 공유 링크** (예: `https://naver.me/I55aZqB6`)
- 교통편 안내 (자가용·버스·지하철·셔틀/대절버스)

---

## 2. `venue` 블록

| 필드 | 설명 | 어디에 쓰이나 |
|---|---|---|
| `name` | 예식장 이름 | 오시는 길 제목, 카카오맵·티맵 검색어, 지도 위치 검색 1순위 |
| `address` | 도로명 주소 (짧게) | 오시는 길 주소 표시 + **주소 복사** 버튼, 지도 위치 검색 2순위 |
| `addressFull` | 주소 + 지번 (예: `영동대로 506(삼성동168-3)`) | 지도 위치 검색 3순위 |
| `tel` | 전화번호 | `Tel.` 표시 |
| `lat` / `lng` | **위도 / 경도** | 위 검색이 모두 실패했을 때의 지도 위치·티맵 도착지 (예비값) |
| `naverPlaceId` | **네이버 장소 ID** | 네이버 지도 버튼 |
| `mapSearchName` | (선택) 지도 검색어 | 카카오맵·네이버·티맵 버튼과 지도 위치 검색에 `name` 대신 사용 |
| `location.theme01~03.transport` | 테마별 교통편 안내 | 오시는 길 하단 |

> 페이지 안 지도는 접속 시 카카오 지도에서 `name` → `address` → `addressFull` 순서로
> 위치를 자동 검색합니다. 그래서 `lat`/`lng` 가 틀려도 지도는 맞게 나올 수 있지만,
> 검색이 실패하는 경우를 대비해 **반드시 실제 좌표로** 바꿔 두세요.
>
> 반면 **네이버 지도 버튼은 `naverPlaceId` 만** 보고 이동하므로, 이 값이 틀리면
> 무조건 엉뚱한 장소가 열립니다.

> **`name` 에 층·홀 이름을 붙이고 싶을 때** (예: `더베일리하우스 삼성점 2F`)
> 카카오 검색은 "2F" 같은 단어가 붙으면 결과가 없습니다. 이럴 땐
> `name: "더베일리하우스 삼성점 2F"`, `mapSearchName: "더베일리하우스 삼성점"` 처럼
> 검색어를 따로 지정하세요. 화면에는 `name`, 지도 버튼에는 `mapSearchName` 이 쓰입니다.

### 2-1. 네이버 장소 ID 찾기

1. 네이버 지도 공유 링크(`naver.me/...`)를 브라우저에서 엽니다.
2. 주소창이 `https://map.naver.com/p/entry/place/520612610?...` 처럼 바뀝니다.
3. `place/` 뒤의 숫자(`520612610`)가 `naverPlaceId` 입니다. (문자열로 입력: `"520612610"`)

### 2-2. 좌표(lat / lng) 찾기

아래 중 편한 방법 하나:

- **구글 지도**: 예식장 위치를 마우스 오른쪽 클릭 → 맨 위 숫자(`37.509788, 127.06318`)를 클릭하면 복사됨
  → 앞 숫자가 `lat`(위도, 37.xxx), 뒤 숫자가 `lng`(경도, 127.xxx)
- **Claude에게 요청**: "주소 ○○, 네이버 링크 ○○ 로 좌표랑 장소 ID 바꿔줘"
  (로컬 미리보기의 카카오 지도 검색으로 좌표를 찾아 반영)

> 주의: 위도/경도를 거꾸로 넣으면 지도가 바다 한가운데로 갑니다.
> 한국은 **lat ≈ 33~38**, **lng ≈ 124~132**.

## 3. `venue` 밖에도 예식장 이름이 들어가는 곳

| 위치 | 필드 |
|---|---|
| 예식 안내 | `dateDisplay.venueShort` |
| 링크 미리보기(OG) 설명 | `meta.ogDescription` |
| 카카오톡 공유 설명 | `share.description` |
| (사용 시) 안내 사항 | `information[].lines` |

---

## 4. 확인 방법

1. `npm run dev` 실행 → `http://localhost:5173/<slug>` 접속
2. 오시는 길 섹션에서:
   - [ ] 페이지 안 지도 마커가 예식장 위치에 찍히는지
   - [ ] 주소 옆 **복사 버튼** → 붙여넣기 해서 주소가 맞는지
   - [ ] **네이버 지도** 버튼 → 해당 예식장이 열리는지
   - [ ] **카카오맵** 버튼 → 해당 예식장이 검색되는지
   - [ ] **티맵** 버튼(모바일) → 도착지가 맞는지
3. config 에서 이전 예식장 이름으로 검색해 남은 곳이 없는지 확인
